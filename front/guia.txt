+------------------------------------------------------------------------------+
| 1. PRE-REQUISITOS                                                            |
+------------------------------------------------------------------------------+

  - Node.js 18+ instalado (verifique: node --version)
  - npm 9+ ou yarn/pnpm
  - Navegador moderno (Chrome, Firefox, Edge)
  - Resolucao minima: 1366x768 (ideal 1920x1080)

+------------------------------------------------------------------------------+
| 2. COMO RODAR LOCALMENTE                                                     |
+------------------------------------------------------------------------------+

  PASSO 1 - Abrir terminal na pasta do dashboard:
  ----------------------------------------------
    cd Projeto-AlfabetizandosEJA/dashboard

  PASSO 2 - Instalar dependencias (apenas na primeira vez):
  ---------------------------------------------------------
    npm install

  PASSO 3 - Iniciar servidor de desenvolvimento:
  ----------------------------------------------
    npm run dev

  PASSO 4 - Abrir no navegador:
  ------------------------------
    >> http://localhost:5173

    O Vite mostrara no terminal:
      VITE v5.x.x  ready in XXX ms
      >> Local:   http://localhost:5173/

+------------------------------------------------------------------------------+
| 3. COMANDOS UTEIS                                                            |
+------------------------------------------------------------------------------+

  npm run dev        # Desenvolvimento com hot-reload
  npm run build      # Build de producao (gera pasta dist/)
  npm run preview    # Testar build local (http://localhost:4173)
  npm run lint       # Verificar codigo (ESLint)

+------------------------------------------------------------------------------+
| 4. ESTRUTURA DO DASHBOARD - NAVEGACAO                                        |
+------------------------------------------------------------------------------+

  VISAO GERAL (/)
     - KPIs: Total, Estados, Idade Media, % Urbano/Rural
     - Grafico de Barras: Top 10 Estados (ano selecionado)
     - Pizza: Distribuicao Raca/Cor + Zona (lado a lado)
     - Filtros: Ano [2016/2025] | Estado | Zona | Raca/Cor

  POR ESTADO (/estado)
     - Seletor de Estado (dropdown com 9 estados NE)
     - KPIs do estado selecionado
     - Graficos: Faixa Etaria, Raca/Cor, Zona, Entidades
     - Tabela paginada com dados individuais (nome, idade, etc.)

  COMPARATIVO (/comparativo)
     - Estados em comum: AL, PI, SE (3 estados)
     - Barras agrupadas: Total por estado (2016 vs 2025)
     - Linha: Evolucao faixa etaria
     - Diff cards: Crescimento/queda % por estado
     - Insights automaticos calculados

  - Sempre explique: "Comparativo valido apenas para AL, PI, SE"

+------------------------------------------------------------------------------+
| 7. TROUBLESHOOTING                                                           |
+------------------------------------------------------------------------------+

  PROBLEMA: "Pagina em branco / erro no console"
  ------------------------------------------------
  >> Verifique se esta na pasta correta: cd dashboard
  >> Rode: rm -rf node_modules package-lock.json && npm install
  >> Confira Node: node --version (precisa 18+)

  PROBLEMA: "Graficos nao aparecem / dados nao carregam"
  ------------------------------------------------------
  >> Abra DevTools (F12) -> Console -> procure erros CORS/CSV
  >> Verifique se CSVs estao em public/data/
  >> Hard refresh: Ctrl+Shift+R (limpa cache)

  PROBLEMA: "Porta 5173 ocupada"
  -------------------------------
  >> Vite tenta 5174, 5175... automaticamente
  >> Ou force: npm run dev -- --port 3000

  PROBLEMA: "Build falha no deploy"
  ---------------------------------
  >> Rode local: npm run build
  >> Verifique erros TypeScript/ESLint
  >> Corrija antes de fazer deploy
