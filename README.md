# Projeto Alfabetizandos EJA

## Descrição

Este projeto tem como objetivo realizar um processo completo de análise de dados utilizando informações públicas do programa de Educação de Jovens e Adultos (EJA), disponibilizadas pelo Governo Federal.

Foram utilizadas bases de dados referentes aos anos de 2016 e 2025, permitindo a comparação entre diferentes períodos e a identificação de possíveis mudanças no perfil dos alfabetizandos ao longo do tempo.

## Objetivos

- Realizar o processo de ETL (Extração, Transformação e Carga) dos dados.
- Tratar inconsistências e padronizar informações.
- Comparar indicadores entre os anos de 2016 e 2025.
- Analisar características dos alfabetizandos, como:
  - Faixa etária;
  - Raça/Cor;
  - Zona de residência (urbana ou rural);
  - Distribuição geográfica.
- Produzir visualizações gráficas para facilitar a interpretação dos dados.
- Desenvolver dashboards interativos para apresentação dos resultados.

## Tecnologias Utilizadas

- Python
- Pandas
- Excel

## Resultados Esperados

A partir da análise das bases de dados, espera-se identificar tendências, diferenças e possíveis evoluções nos indicadores relacionados à alfabetização de jovens e adultos, fornecendo uma visão comparativa entre os anos analisados.

## Fonte dos Dados

Dados públicos disponibilizados pelo programa de Educação de Jovens e Adultos (EJA) através dos portais governamentais brasileiros.
